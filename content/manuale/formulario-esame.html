1. Teoria Atomica

Onde elettromagnetiche

Relazione lunghezza d'onda - frequenza
λ = c / ν
  • λ = lunghezza d'onda [m]
  • ν = frequenza [Hz = s−1]
  • c = 2,99 × 108 m/s
Energia del fotone
E = hν = hc/λ
  • E = energia [J]
  • h = 6,63 × 10−34 J·s
Numero d'onda
k̄ = 1/λ = ν/c

Spettro dell'idrogeno

Formula di Rydberg (transizioni n₁ → n₂)
1/λ = RH × (1/n₁² − 1/n₂²)

RH = 1,097 × 107 m−1

Formula di Balmer (transizioni verso n = 2)
λ = B × n² / (n² − 4)

B = 3,65 × 10−7 m = 364,56 nm

Effetto fotoelettrico

Bilancio energetico
hν = ω + Ecinetica = hν₀ + ½mv²
  • ω = hν₀ = lavoro di estrazione
  • ν₀ = frequenza di soglia

Modello di Bohr

Raggi permessi
rn = n² × a₀

a₀ = 0,53 Å = 5,3 × 10−11 m

Energia dell'elettrone al livello n
En = −E₀ / n²

E₀ = 13,60 eV = 2,179 × 10−18 J (per H)

Energia di transizione
ΔE = E₀ × (1/ni² − 1/nf²) = hν
Carica formale
Cform = e−valenza − e−legame/2 − e−non leg.

Polarità e risonanza

Polarità del legame presente se:
  • Legame tra atomi diversi
  • Legame tra atomi uguali legati ad atomi diversi
  • Asimmetria dei doppietti rispetto all'atomo centrale
Strutture di risonanza - preferire quelle con:
  1. Cariche formali ridotte
  2. Nessuna carica uguale su atomi adiacenti
  3. Carica negativa sull'atomo più elettronegativo
Magnetismo: Paramagnetico = almeno 1 e− spaiato | Diamagnetico = tutti appaiati

3. Stechiometria

Mole e massa

Definizione di mole
n = m / M
  • n = moli [mol]
  • m = massa [g]
  • M = massa molare [g/mol]
Numero di particelle
N = n × NA

NA = 6,022 × 1023 mol−1

Massa atomica media
mmedia = Σ (misotopo × abbondanza)

Composizione

Composizione percentuale
%elemento = (melemento / mcomposto) × 100
Frazione in massa
x = n × (Melemento / Mcomposto)
Densità
ρ = m / V    [g/mL]

Reazioni

Rapporto molare
rapporto = coeffprodotto / coeffreagente
Reagente limitante
x è limitante se: nx/coeffx < naltro/coeffaltro
Resa percentuale
η% = (quantità ottenuta / quantità teorica) × 100

Ossidoriduzioni

Numeri di ossidazione standard:
  • O = −2 (perossidi: −1)
  • H = +1 (idruri: −1)
  • Elementi puri = 0
  • Σ n.o. × n°atomi = carica totale

6. Acidi e Basi

Costanti di equilibrio

Costante di acidità Ka
HA + H₂O ⇄ H₃O+ + A−
Ka = [H₃O+][A−] / [HA]
Costante di basicità Kb
B + H₂O ⇄ OH− + BH+
Kb = [OH−][BH+] / [B]
Relazione fondamentale
Ka × Kb = Kw = 10−14

pH e pOH

Definizioni di pH
pH = −log₁₀[H₃O+]   ⟹   [H₃O+] = 10−pH
pOH = −log₁₀[OH−]   ⟹   [OH−] = 10−pOH
pH + pOH = 14
Definizioni di pK
pKa = −log₁₀(Ka)     pKa + pKb = 14

Acidi e basi forti

Dissociazione completa (α = 1)
[H₃O+] = Ca × VO     [OH−] = Cb × VO

Acidi e basi deboli

Approssimazione per acidi deboli (Ca >> [H₃O+])
[H₃O+] = √(Ka × Ca)
pH = ½pKa − ½log Ca
Approssimazione per basi deboli
[OH−] = √(Kb × Cb)
pOH = ½pKb − ½log Cb
Grado di dissociazione
α = [A−] / Ca     %diss = α × 100

Classificazione forza acida

KaAcidoBase coniugata
Ka > 1forte—
10−4 < Ka < 1medio-fortemedio-debole
10−7 < Ka < 10−4medio-debolemedio-forte
Ka < 10−7—forte

Idrolisi dei sali

Composizione salepH soluzione
acido forte + base forteneutro (no idrolisi)
acido debole + base fortebasico
acido forte + base deboleacido
acido debole + base deboledipende da Ka e Kb
Costante di idrolisi
Ki = Kw / Ka   (sol. basica)     Ki = Kw / Kb   (sol. acida)
pH sale (acido debole + base forte)
pH = 7 + ½pKa + ½log Cs
pH sale (acido forte + base debole)
pH = 7 − ½pKb − ½log Cs

Soluzioni tampone

Equazione di Henderson-Hasselbalch
pH = pKa + log([A−]/[HA]) = pKa + log(Csale/Cacido)
Con aggiunta di acido/base forte
+ acido: pH = pKa + log((Cs − a)/(Ca + a))
+ base: pH = pKa + log((Cs + b)/(Ca − b))

Indicatori

Intervallo di viraggio

7. Termodinamica

I Principio

Bilancio energetico
ΔU = q + w
  • q = calore (+ se assorbito dal sistema)
  • w = lavoro (+ se fatto sul sistema)
Lavoro di espansione
w = −PΔV = −∫P dV
Lavoro isotermo (gas ideale)
w = −nRT ln(V₂/V₁)

Casi particolari

CondizioniProcessoRisultato
q = 0, w = 0sistema isolatoΔU = 0
q = 0adiabaticoΔU = w
w = 0 (V cost)isocoroΔU = qv
ΔU = 0ciclicoq = −w

Capacità termica

Capacità termica
C = q/ΔT     Cspec = m×q/ΔT     Cmol = n×q/ΔT

Entalpia

Definizione di entalpia
ΔH = qp = ΔU + PΔV
  • ΔH < 0: esotermica
  • ΔH > 0: endotermica
Relazione qp e qv (gas)
qp = qv + ΔnRT
Entalpia di reazione
ΔH°reaz = Σ ΔH°f(prodotti) − Σ ΔH°f(reagenti)
Legge di Hess
ΔH°tot = Σ ΔH°i

Se inverti reazione → cambia segno. Se moltiplichi → moltiplica ΔH°

Entropia

Variazione di entropia
ΔS = qrev / T
II Principio: ΔSuniverso ≥ 0
III Principio: S → 0 quando T → 0 K
Rendimento (ciclo di Carnot)
η = |w|/|qass| = 1 − |qril|/|qass|
ηmax = 1 − Tfreddo/Tcaldo

Energia libera di Gibbs

Definizione
G = H − TS     ΔG = ΔH − TΔS
ΔGSignificato
ΔG < 0spontaneo
ΔG = 0equilibrio
ΔG > 0non spontaneo
Relazioni fondamentali
ΔG = ΔG° + RT ln Q
ΔG° = −RT ln K

All'equilibrio (Q = K): ΔG = 0

Equilibri chimici

Quoziente di reazione (aA + bB → cC + dD)
Qc = [C]c[D]d / ([A]a[B]b)
Qp = pCc·pDd / (pAa·pBb)
Relazione Kp e Kc
Kp = Kc × (RT)Δn

Δn = (c + d) − (a + b)

Equazione di Van't Hoff
ln(K₂/K₁) = −(ΔH°/R) × (1/T₂ − 1/T₁)

8. Cinetica Chimica

Velocità di reazione

Definizione (aA + bB → cC + dD)
v = −(1/a)(d[A]/dt) = (1/c)(d[C]/dt)
Legge cinetica
v = k[A]α[B]β

Ordine complessivo = α + β

Unità della costante k

OrdineUnità di k

Reazioni di I ordine

Legge integrata
ln[A] = −kt + ln[A]₀     [A] = [A]₀ × e−kt
Tempo di dimezzamento
t½ = ln2 / k = 0,693 / k

(indipendente da [A]₀)

Reazioni di II ordine

Legge integrata
1/[A] = kt + 1/[A]₀
Tempo di dimezzamento
t½ = 1 / (k[A]₀)

Determinazione dell'ordine

Grafico lineareOrdinePendenza

Relazione k e K (all'equilibrio)
K = kdir / kinv

Equazione di Arrhenius

Forma esponenziale
k = A × e−Ea/RT
Forma logaritmica
ln k = ln A − Ea/(RT)
Due temperature
ln(k₂/k₁) = (Ea/R) × (1/T₁ − 1/T₂)
Energia di attivazione
Ea = R × (T₁T₂)/(T₂ − T₁) × ln(k₂/k₁)
Meccanismo: Lo stadio lento (Ea maggiore) determina la velocità globale

9. Elettrochimica

Grandezze elettriche

GrandezzaSimboloFormulaUnità
CaricaqC
CorrenteII = q/tA = C/s
PotenzialeE, ΔEV = J/C
ResistenzaRR = V/IΩ
PotenzaPP = VIW
LavoroWW = qVJ

Pile galvaniche

Schema pila: (−) Anodo | Sol₁ ‖ Sol₂ | Catodo (+)
Anodo (−): ossidazione    Catodo (+): riduzione
Forza elettromotrice
ΔE = Ecatodo − Eanodo

Per funzionare: Ecatodo > Eanodo

Equazione di Nernst

Forma generale
ΔE = ΔE° − (RT)/(nF) × ln Q
A 25°C (forma semplificata)
ΔE = ΔE° − (0,059/n) × log₁₀ Q

n = numero di elettroni scambiati

Per semicella
E = E° − (0,059/n) × log([ridotto]/[ossidato])

Energia libera e potenziale

Relazione ΔG - ΔE
ΔG = −nFΔE     ΔG° = −nFΔE°

Leggi di Faraday

Massa depositata
m = (M × q) / (n × F) = (M × I × t) / (n × F)
  • F = 96485 C/mol
  • M = massa molare
  • n = elettroni scambiati
Moli depositate
mol = q / (n × F) = (I × t) / (n × F)

Pile a concentrazione

Schema: (+) M | M+(C₂) ‖ M+(C₁) | M (−) con C₁ > C₂
ΔE = (0,059/n) × log(C₁/C₂)

Elettrolisi dell'acqua

Anodo (+): 2H₂O → O₂ + 4H+ + 4e−
Catodo (−): 2H₂O + 2e− → H₂ + 2OH−

Elettrochimica - Quick reference

Ricorda sempre:

  • Nernst a 25°C: ΔE = ΔE° − (0,059/n) × log Q
  • Faraday: m = (M × I × t) / (n × F)
  • Energia: ΔG° = −nFΔE°
  • Pila funziona se: Ecatodo > Eanodo (ΔE > 0)
